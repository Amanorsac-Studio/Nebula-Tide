NEBULA TIDE 1.1.7
===============

An ocean of sound, in every key. Endless drone pads — real recordings in all
12 keys — with FX and texture layers, inside an interface that's alive.
Runs as a standalone app and as a VST3 plugin.

WINDOWS INSTALL
---------------
1. Run  NebulaTide-1.1.7-Setup.exe
   (If Windows SmartScreen appears, click "More info" -> "Run anyway".)
2. Tick "Install VST3 plugin" to use it inside your DAW.

Installed locations:
   App ........ C:\Program Files\Nebula Tide\Nebula Tide.exe
   VST3 ....... C:\Program Files\Common Files\VST3\Nebula Tide.vst3
   Sounds ..... C:\ProgramData\Nebula Tide\presets

If you downloaded the SOUND LIBRARY separately (NebulaTide-Sounds-1.1.0.zip),
unzip it so the files land in  C:\ProgramData\Nebula Tide\presets

macOS INSTALL
-------------
Run  NebulaTide-1.1.7-macOS.pkg  — one installer for everything:
   App ........ /Applications/Nebula Tide.app
   VST3 ....... /Library/Audio/Plug-Ins/VST3/Nebula Tide.vst3
   AU ......... /Library/Audio/Plug-Ins/Components/Nebula Tide.component
   Sounds ..... /Library/Application Support/Nebula Tide/presets
(If macOS says the installer is from an unidentified developer: right-click
the .pkg -> Open -> Open.)

ANDROID: install NebulaTide-Android*.apk (sideload) or via Google Play. The sound
library is inside the app; first launch takes a moment to unpack it. No internet
connection is ever needed.

iPad: available through the App Store / TestFlight only (Apple does not allow
installing iPad apps from a download).

QUICK START
-----------
- Click the big square in the middle to start the drone. Click again to stop.
- Tap a planet along the orbit to change key (12 keys, real recordings).
- Left star = FX, right star = textures. Click to play/stop, < > to change
  sound, the infinity symbol toggles looping, drag up/down on a star = volume.
- ROOM / PLATE / HALL choose the reverb character; MIX / SIZE / DAMP fine-tune.
- < > at the top switch presets. The whole interface re-colours per preset.
- KEYS (top right) shows a Kontakt-style keyboard with the MIDI zones.

PLAY IT FROM A KEYBOARD OR MIDI DEVICE
--------------------------------------
- Computer keyboard: A W S E D F T G Y H U J = C..B | Space = play/stop
  Left/Right = presets | 1 = FX star | 2 = texture star
- MIDI zones: FX C2-B2 (one note per sound) | KEYS C3-B4 (pitch = key) |
  TEXTURES C5-B5 (one note per sound). In a DAW, piano-roll notes gate the
  pad like a sampler (switchable in SETTINGS).
- MIDI Learn: right-click any control and choose "MIDI Learn", then move a
  knob or press a pad on your controller. SETTINGS shows every binding and
  your audio/MIDI device setup.

UNINSTALL
---------
Windows Settings -> Apps -> Nebula Tide -> Uninstall.
